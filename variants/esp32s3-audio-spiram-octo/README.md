# ESP32S3-AUDIO-SPIRAM-OCTO

A variant of the ESP32S3 envelope that configures the external SPI RAM
to use octal SPI and includes the full set of audio primitives.

This enables packed-PCM processing, additional audio DSP operations,
and float32 complex FFT operations. Use this variant for audio and
spectral-processing applications on ESP32S3 boards with octal PSRAM.
